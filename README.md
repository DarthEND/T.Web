# Laboratoarele pentru Tehnologii Web

Acest repository centralizează laboratoarele pentru disciplina **Tehnologii Web**.

## Structura pe branch-uri

- **`Lab-1_HTML`** — versiunea de bază în HTML (pagini statice pentru abonamente, internet, internet+TV și prepay).
- **`lab-2_CSS`** — extinderea laboratorului 1 cu stilizare CSS (`css/styles.css`).
- **`Lab-3_JAVASCRIPT`** — adaugă funcționalități JavaScript (filtrare și comparare oferte, pagină `compare`).
- **`Lab-4_PHP`** — migrare către PHP (template-uri, date separate în `data/`, pagini `.php`, dashboard).
- **`Lab-5_AJAX`** — continuarea pe PHP cu utilizare AJAX.

## Branch principal

- **`main`** conține acest README de orientare.

## Cum poți explora laboratoarele

1. Listează branch-urile:
   ```bash
   git branch -a
   ```
2. Comută pe branch-ul laboratorului dorit:
   ```bash
   git checkout <nume-branch>
   ```
